# Cuestionario de necesidades de usuarios

**Propósito:** recolectar necesidades reales para priorizar mejoras de Tienda de Deportes. No completar respuestas por inferencia.

**Consentimiento:** participación voluntaria; explicar uso académico de las respuestas y no registrar datos personales innecesarios.

1. ¿Qué rol cumple en la tienda? (cliente / ventas / inventario / administración / otro)
2. ¿Qué tareas realiza con más frecuencia?
3. ¿Qué información necesita consultar para completar esas tareas?
4. ¿Cómo registra actualmente productos, variantes, existencias y ventas?
5. ¿Qué errores o demoras aparecen con más frecuencia?
6. ¿Qué alertas de stock considera útiles y con cuánto tiempo de anticipación?
7. ¿Qué pasos espera para una compra presencial? ¿Y para una compra online?
8. ¿Qué estados necesita consultar en un pedido o pago?
9. Para la gestión interna, ¿qué proyectos, fases, responsables y fechas necesita seguir?
10. ¿Qué dispositivo y nivel de conectividad usa normalmente?
11. ¿Qué información debería poder ver cada rol? ¿Qué debería quedar restringido?
12. ¿Qué tres mejoras priorizaría y por qué?

Registrar fecha, perfil general sin identificar a la persona, modalidad y consentimiento en `REGISTRO_RESPUESTAS.md`. Adjuntar evidencia solo con autorización.
